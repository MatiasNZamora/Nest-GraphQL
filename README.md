# 🧩 Descripción del proyecto

Este proyecto consiste en una **API GraphQL desarrollada con NestJS**, donde se implementan funcionalidades completas de backend incluyendo:

- Gestión de usuarios
- Autenticación y autorización
- CRUD de entidades
- Relaciones entre entidades
- Paginación y filtros
- Protección de rutas
- Seed de base de datos
- Deploy en contenedores Docker

El proyecto utiliza el enfoque **Code First**, donde los esquemas GraphQL se generan automáticamente a partir de las entidades y DTOs de TypeScript.

# 🚀 Instalación

Clonar repositorio:

```bash
git clone https://github.com/tuusuario/nestjs-graphql-api

Instalar dependencias:

npm install

Levantar entorno con Docker:

docker-compose up -d

Ejecutar proyecto:

npm run start:dev
📖 GraphQL Playground

Una vez ejecutado el proyecto puedes acceder al playground en:

http://localhost:3000/graphql

Desde allí podrás ejecutar queries y mutations.
